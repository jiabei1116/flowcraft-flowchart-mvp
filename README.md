# FlowCraft 流程图工具 MVP

一个面向产品经理的纯前端流程图编辑器原型。无需安装依赖，直接在浏览器中运行。

## 运行

直接打开 `index.html`，或在当前目录启动任意静态文件服务器。

```powershell
npx serve .
```

## 已实现

- 文件首页、模板新建、最近文件管理
- SVG 画布、拖拽添加、缩放、平移、网格吸附
- 9 种基础图形、节点移动/缩放/多选/框选
- 快速新增并连线、折线/直线、箭头与连线说明
- 节点文字和样式编辑、6 套主题
- 对齐、分布、匹配大小、层级、组合
- 撤销/重做、复制/粘贴、常用快捷键
- 浏览器本地自动保存
- PNG / SVG / PDF 导出
- 基于 URL 快照的只读分享与创建副本

## 数据说明

MVP 使用 `localStorage` 保存文件，不包含账号、后端和多人实时协作。只读分享会把当前流程图快照编码在 URL hash 中，不上传数据。
